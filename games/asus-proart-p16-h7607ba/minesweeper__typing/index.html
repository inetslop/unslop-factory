TYPE MINES

A typing-speed twist on minesweeper. Every tile shows a unique 2-character code.

How to play: type a tile's code to open it and reveal how many mines touch it. Deduce which remaining tiles are safe, then type their codes to clear the board. Open a mine and it's over.

A–Z 1–9 type code  ·  F toggle flag mode  ·  Esc exit flag / clear input
R restart  ·  M menu  ·  mouse: click = open, right-click = flag

Press ENTER to start  (1/2/3 quick-start)

R play again  ·  M menu
